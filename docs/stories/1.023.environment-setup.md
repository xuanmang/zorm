## Dev Notes

### 重要约束: 使用 ZORM API, 禁止直接使用 pg.zig

**核心原则**: 本 Story 的所有示例代码必须通过 ZORM 的公共 API 与数据库交互,**严禁直接导入和使用 pg.zig 包**。

**为什么**:
- ZORM 的价值在于提供类型安全、编译时优化的 ORM 抽象层
- 如果示例直接用 pg.zig,则无法展示 ZORM 的核心功能 (查询构建器、类型映射、编译时反射)
- 用户学习 ZORM 是为了简化数据库操作,而不是学习原始的 PostgreSQL C API 绑定

**允许的做法**:
```zig
const zorm = @import("zorm");

// ✅ 正确: 使用 ZORM 创建 DB 实例
const db = try zorm.DB.init(allocator, conn, .postgresql, .{});

// ✅ 正确: 使用 ZORM 查询构建器
var query = try db.newSelect(User);

// ✅ 正确: 使用 ZORM DDL API
var create_table = try db.newCreateTable(User);
```

**禁止的做法**:
```zig
const pg = @import("pg"); // ❌ 禁止直接导入 pg.zig

// ❌ 禁止: 直接使用 pg.zig 的连接和查询
const conn = try pg.connect(...);
const result = try conn.query("SELECT * FROM users", .{});
```

**特殊情况**:
- **仅在 ZORM 内部实现** (src/ 目录) 才可以使用 pg.zig
- **示例代码** (examples/ 目录) 必须只使用 ZORM 的公共 API

#### Zig 语言关键要点
[Source: docs/architecture.md - 核心设计原则]

##### 内存管理
- **显式 Allocator**: 所有分配都通过 `allocator.create()` / `allocator.alloc()`
- **defer 清理**: 使用 `defer db.deinit()` 确保资源释放
- **错误处理**: 使用 `!T` 错误联合类型, `try` 传播错误

##### Zig 0.15.2 ArrayList 重要变化
[Source: docs/architecture.md - ⚠️ Zig 0.15.2 重要 API 变化]

```zig
// ❌ 错误 (Zig 0.14.x 风格)
var list = std.ArrayList(T).init(allocator);

// ✅ 正确 (Zig 0.15.2+)
var list: std.ArrayList(T) = .{};  // 结构体字面量初始化
defer list.deinit(allocator);      // 必须传递 allocator
try list.append(allocator, item);   // 必须传递 allocator
```

**关键方法的 allocator 参数**:
| 方法 | Zig 0.15.2+ |
|------|-------------|
| 初始化 | `: T = .{}` |
| 释放 | `.deinit(allocator)` |
| 添加元素 | `.append(allocator, item)` |
| 批量添加 | `.appendSlice(allocator, items)` |
| 转移所有权 | `.toOwnedSlice(allocator)` |
| 获取 writer | `.writer(allocator)` |

const std = @import("std");
const testing = std.testing;

test "database config default values" {
    const config = getDefaultConfig();
    try testing.expectEqualStrings("127.0.0.1", config.host);
    try testing.expect(config.port == 5432);
}

test "create DB instance - no memory leaks" {
    const allocator = testing.allocator;  // 自动检测泄漏

    const db = try createDBInstance(allocator);
    defer db.deinit();  // 忘记这行会导致测试失败

    try testing.expect(db.dialect == .postgresql);
