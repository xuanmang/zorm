### 重要约束: 使用 ZORM API, 禁止直接使用 pg.zig

**核心原则**: 本 Story 的所有示例代码必须通过 ZORM 的公共 API 与数据库交互,**严禁直接导入和使用 pg.zig 包**。

**允许的做法**:
```zig

try insert.exec();
```

**禁止的做法**:
```zig
const pg = @import("pg");  // ❌ 禁止直接导入 pg.zig
```

#### 批量操作 API

```zig
// 批量插入
var insert = try db.newInsert(User);
try insert.values(&user_array);  // 一次插入多条
try insert.exec();

// 批量插入并返回结果
var insert = try db.newInsert(User);
try insert.values(&user_array).setReturning("*");
var results: std.ArrayList(User) = .{};
defer results.deinit(allocator);
try insert.execReturning(allocator, &results);

// 批量更新 (使用 CASE WHEN)
const sql =
  \\UPDATE users SET
  \\  name = CASE
  \\    WHEN id = ? THEN ?
  \\    WHEN id = ? THEN ?
  \\    ELSE name
  \\  END
  \\WHERE id IN (?, ?);
try db.newRaw(sql, .{1, "Alice", 2, "Bob", 1, 2}).exec();
```

#### 高级查询 API

```zig
// CTE (WITH 子句)
const sql =
  \\WITH active_users AS (
  \\  SELECT * FROM users WHERE status = 'active'
  \\)
  \\SELECT posts.* FROM posts
  \\JOIN active_users ON posts.user_id = active_users.id;
try db.newRaw(sql, .{}).exec();

// 递归 CTE (树形结构查询)
const sql =
  \\WITH RECURSIVE category_tree AS (
  \\  SELECT id, name, parent_id, 0 as level
  \\  FROM categories WHERE parent_id IS NULL
  \\  UNION ALL
  \\  SELECT c.id, c.name, c.parent_id, ct.level + 1
  \\  FROM categories c
  \\  JOIN category_tree ct ON c.parent_id = ct.id
  \\)
  \\SELECT * FROM category_tree ORDER BY level, id;
try db.newRaw(sql, .{}).exec();

// 窗口函数
const sql =
  \\SELECT
  \\  id,
  \\  name,
  \\  ROW_NUMBER() OVER (ORDER BY created_at DESC) as row_num,
  \\  RANK() OVER (PARTITION BY status ORDER BY created_at) as rank,
  \\  LAG(id) OVER (ORDER BY created_at) as prev_id
  \\FROM users;
try db.newRaw(sql, .{}).exec();
```

### 性能优化提示

1. **批量插入性能对比**:
   - 逐条插入: ~100 records/sec
   - 批量插入: ~10,000 records/sec
   - COPY 协议: ~100,000 records/sec

2. **CTE vs 子查询**:
   - CTE 提高可读性,可复用
   - 某些情况下性能略低于子查询
   - PostgreSQL 12+ 支持 CTE 内联优化

3. **递归 CTE**:
   - 适用于树形结构、图遍历
   - 注意设置递归深度限制
   - 避免无限递归
