# Story 2.1: Type-Safe UPDATE Query Builder

**Epic**: 2 - Complete CRUD & Transaction Support
**Story**: 2.1
**Status**: Ready for Review

---

## Story

**As a** Zig developer,
**I want** 使用类型安全的 UPDATE 构建器修改数据库记录,
**so that** 我能够以声明式方式更新数据，避免手写 SQL 错误。

---

## Acceptance Criteria

1. **AC2.1.1**: 提供 `db.newUpdate(T)` API 创建 UPDATE 查询构建器
2. **AC2.1.2**: 提供 `.set(assignments)` 方法指定要更新的列和值（支持字符串表达式或结构体）
3. **AC2.1.3**: 支持 `.where(condition, args)` 方法添加 WHERE 条件（防止误更新所有行）
4. **AC2.1.4**: 提供 `.exec()` 方法执行更新，返回 `UpdateResult`（包含 rows_affected）
5. **AC2.1.5**: 支持 `.setReturning(cols)` 方法启用 PostgreSQL RETURNING 子句
6. **AC2.1.6**: 提供 `.execReturning(dest)` 方法执行更新并获取更新后的数据
7. **AC2.1.7**: 支持链式调用和多个 WHERE 条件组合
8. **AC2.1.8**: 完整使用示例验证工作流程

## Dev Notes

### 架构参考

**UpdateQuery 设计** [Source: architecture/architecture-core.md#Query Builders]:
- 遵循与 SelectQuery/InsertQuery 相同的 Builder Pattern
- 支持 Fluent Interface（链式调用返回 *Self）
- 泛型类型 T 在编译时确定目标结构体
- build() 和 exec() 分离，支持 SQL 预览

**类型安全** [Source: architecture/architecture-core.md#Type System]:
- 使用 `getTableName(T)` 自动推断表名
- 参数绑定防止 SQL 注入
- 错误联合类型强制错误处理

**PostgreSQL RETURNING** [Source: prd.md#FR4]:
- PostgreSQL 特有功能，避免 UPDATE 后再 SELECT
- 支持返回更新后的完整行数据
- 使用 `RETURNING *` 或指定列

### 实现约束

**SQL 生成规则** [Source: architecture/coding-standards.md#禁止规则]:
- ❌ 禁止字符串拼接 SQL
- ✅ 使用参数绑定（$1, $2 占位符）
- ✅ 所有用户输入必须通过参数传递

**内存管理** [Source: architecture/coding-standards.md#内存管理]:
- 所有 ArrayList 使用 Zig 0.15.2+ API: `var list: std.ArrayList(T) = .{};`
- deinit() 时传递 allocator: `list.deinit(allocator)`
- 使用 errdefer 处理错误路径清理

**错误处理** [Source: architecture/coding-standards.md#错误处理]:
- exec() 返回 `!UpdateResult` error union
- 使用 `try` 传播错误，避免 `catch` 吞没错误
- 定义清晰的错误类型（error.NoRows, error.SQLSyntaxError）

### Bun ORM 对齐

**API 一致性** [Source: prd.md#Background Context]:
```zig
// ZORM (Zig) - 与 Bun ORM 使用方式一致
var update = try db.newUpdate(User);
defer update.deinit();

const result = try update
    .set("age = age + 1, updated_at = ?", .{std.time.timestamp()})
    .where("email = ?", .{"alice@example.com"})
    .exec();

// Bun ORM (TypeScript)
const result = await db.update(User)
    .set({ age: age + 1, updated_at: new Date() })
    .where({ email: "alice@example.com" })
    .exec();
```
