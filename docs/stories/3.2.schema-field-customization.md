# Story 3.2: Schema Field Customization with Struct Tags

**Epic**: 3 - Schema Management & Type System
**Story**: 3.2
**Status**: Ready for Review

---

## Story

**As a** Zig developer,
**I want** 自定义表字段的属性（如列名、类型、约束、默认值），
**so that** 我能够精确控制生成的 Schema 而不受 Zig 结构体字段命名限制。

---

## Acceptance Criteria

1. **AC3.2.1**: 支持通过结构体字段上的 comptime 元数据定义列属性
2. **AC3.2.2**: 支持自定义列名（如 Zig 字段 `user_name` 映射到 SQL 列 `username`）
3. **AC3.2.3**: 支持显式指定 SQL 类型（覆盖自动推断）
4. **AC3.2.4**: 支持 UNIQUE 约束标记
5. **AC3.2.5**: 支持 DEFAULT 值设置
6. **AC3.2.6**: 支持 CHECK 约束
7. **AC3.2.7**: 使用 Zig comptime 结构定义 Schema 配置（参考 Bun 的 struct tags）
8. **AC3.2.8**: 完整的使用示例验证

### Relevant Architecture Context

**Schema Manager Design** [Source: docs/architecture/architecture-core.md#5-schema-manager]:
```zig
const User = struct {
    id: i64,
    username: []const u8,
    email: []const u8,
    age: u32,
    status: []const u8,
    created_at: i64,

    pub const table_name = "users";

    // Schema 配置 (comptime)
    pub const schema = .{
        .id = .{ .primary_key = true, .auto_increment = true },
        .username = .{ .unique = true, .sql_type = "VARCHAR(50)" },
        .email = .{ .unique = true },
        .age = .{ .check = "age >= 0 AND age <= 150" },
        .status = .{ .default = "'active'" },
        .created_at = .{ .default = "CURRENT_TIMESTAMP" },
    };
};
```

    email TEXT UNIQUE NOT NULL,
    age INTEGER NOT NULL CHECK (age >= 0 AND age <= 150),
    status TEXT NOT NULL DEFAULT 'active',
    created_at BIGINT NOT NULL DEFAULT CURRENT_TIMESTAMP

### Key Implementation Notes

**FieldSchema 结构体定义**:
```zig
pub const FieldSchema = struct {
    column_name: ?[]const u8 = null,
    sql_type: ?[]const u8 = null,
    primary_key: bool = false,
    auto_increment: bool = false,
    unique: bool = false,
    default: ?[]const u8 = null,
    check: ?[]const u8 = null,
    not_null: ?bool = null,
};
```

**读取 Schema 配置示例**:
```zig
pub fn getFieldSchema(comptime T: type, comptime field_name: []const u8) FieldSchema {
    if (!@hasDecl(T, "schema")) return .{};

    const schema_config = T.schema;
    if (@hasField(@TypeOf(schema_config), field_name)) {
        return @field(schema_config, field_name);
    }

    return .{};
}
```

**列定义生成更新**:
```zig
pub fn generateColumnDefinition(
    comptime field_name: []const u8,
    comptime field_type: type,
    comptime schema_cfg: FieldSchema,
) []const u8 {
    const col_name = schema_cfg.column_name orelse field_name;
    const is_optional = @typeInfo(field_type) == .Optional;
    const base_type = if (is_optional) @typeInfo(field_type).Optional.child else field_type;

    // SQL 类型
    var sql_type = schema_cfg.sql_type orelse blk: {
        if (schema_cfg.auto_increment) {
            if (base_type == i64) break :blk "BIGSERIAL";
            if (base_type == i32) break :blk "SERIAL";
        }
        break :blk zigToSQLType(base_type);
    };

    // 约束
    var constraints: []const []const u8 = &.{};
    if (schema_cfg.primary_key) constraints = constraints ++ &[_][]const u8{"PRIMARY KEY"};
    if (schema_cfg.unique) constraints = constraints ++ &[_][]const u8{"UNIQUE"};

    const not_null = schema_cfg.not_null orelse !is_optional;
    if (not_null and !schema_cfg.auto_increment) {
        constraints = constraints ++ &[_][]const u8{"NOT NULL"};
    }

    if (schema_cfg.default) |default_val| {
        constraints = constraints ++ &[_][]const u8{
            std.fmt.allocPrint("DEFAULT {s}", .{default_val})
        };
    }

    if (schema_cfg.check) |check_expr| {
        constraints = constraints ++ &[_][]const u8{
            std.fmt.allocPrint("CHECK ({s})", .{check_expr})
        };
    }

    // 组装
    return std.fmt.allocPrint("{s} {s} {s}", .{
        col_name,
        sql_type,
        std.mem.join(" ", constraints),
    });
}
```

### PostgreSQL SERIAL 类型说明

- `SERIAL` = `INTEGER` + `AUTO_INCREMENT`
- `BIGSERIAL` = `BIGINT` + `AUTO_INCREMENT`
- PostgreSQL 会自动创建序列并设置默认值
