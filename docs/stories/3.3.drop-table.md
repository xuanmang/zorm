# Story 3.3: DROP TABLE Query Builder

**Epic**: 3 - Schema Management & Type System
**Story**: 3.3
**Status**: Draft

---

## Story

**As a** Zig developer,
**I want** 使用 DROP TABLE 构建器删除数据库表，
**so that** 我能够在测试或清理场景中安全地删除表结构。

---

## Acceptance Criteria

1. **AC3.3.1**: 提供 `db.newDropTable(T)` API 创建 DROP TABLE 查询构建器
2. **AC3.3.2**: 自动从 Zig 结构体获取表名
3. **AC3.3.3**: 提供 `.ifExists()` 方法添加 IF EXISTS 子句（避免表不存在时报错）
4. **AC3.3.4**: 提供 `.cascade()` 方法添加 CASCADE 选项（级联删除依赖对象）
5. **AC3.3.5**: 提供 `.restrict()` 方法添加 RESTRICT 选项（有依赖时拒绝删除，默认行为）
6. **AC3.3.6**: 提供 `.exec()` 方法执行 DDL 语句
7. **AC3.3.7**: 完整的使用示例验证

```zig
pub fn DropTableQuery(comptime T: type) type {
    return struct {
        const Self = @This();
        allocator: Allocator,
        db: *DB,
        table_name: []const u8,
        if_exists_flag: bool,
        cascade_flag: bool,
        restrict_flag: bool,

        pub fn ifExists(self: *Self) *Self;
        pub fn cascade(self: *Self) *Self;
        pub fn restrict(self: *Self) *Self;
        pub fn build(self: *Self) ![]const u8;
        pub fn exec(self: *Self) !void;
        pub fn deinit(self: *Self) void;
    };
}
```

### PostgreSQL CASCADE vs RESTRICT

**CASCADE** [PostgreSQL Documentation]:
- 级联删除所有依赖对象（视图、外键约束等）
- 谨慎使用，可能删除意外的对象

**RESTRICT** (默认):
- 如果有依赖对象，拒绝删除并返回错误
- 更安全，防止误删

**互斥性**:
- CASCADE 和 RESTRICT 不能同时使用
- 如果同时调用 .cascade() 和 .restrict()，后者覆盖前者

### Coding Standards

**链式 API 模式** [Source: docs/architecture/coding-standards.md]:
- 所有链式方法返回 `*Self`
- 支持流畅接口: `.ifExists().cascade().exec()`

**内存管理** [Source: docs/architecture/coding-standards.md#内存管理规范]:
- 所有 API 必须接受 `Allocator` 参数
- 提供 `deinit()` 方法释放资源

### Key Implementation Notes

**SQL 构建示例**:
```zig
pub fn build(self: *Self) ![]const u8 {
    var sql_buf: std.ArrayList(u8) = .{};
    errdefer sql_buf.deinit(self.allocator);

    try sql_buf.appendSlice(self.allocator, "DROP TABLE ");

    if (self.if_exists_flag) {
        try sql_buf.appendSlice(self.allocator, "IF EXISTS ");
    }

    try sql_buf.appendSlice(self.allocator, self.table_name);

    if (self.cascade_flag) {
        try sql_buf.appendSlice(self.allocator, " CASCADE");
    } else if (self.restrict_flag) {
        try sql_buf.appendSlice(self.allocator, " RESTRICT");
    }

    defer sql_buf.deinit(self.allocator);
    return self.allocator.dupe(u8, sql_buf.items);
}
```

**链式调用示例**:
```zig
var drop = try db.newDropTable(User);
defer drop.deinit();

try drop
    .ifExists()
    .cascade()
    .exec();
```
