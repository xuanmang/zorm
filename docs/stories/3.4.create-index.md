# Story 3.4: CREATE INDEX Query Builder

**Epic**: 3 - Schema Management & Type System
**Story**: 3.4
**Status**: Draft

---

## Story

**As a** Zig developer,
**I want** 使用 CREATE INDEX 构建器为表创建索引，
**so that** 我能够优化查询性能，特别是对频繁查询的列。

---

## Acceptance Criteria

1. **AC3.4.1**: 提供 `db.newCreateIndex(T)` API 创建 CREATE INDEX 查询构建器
2. **AC3.4.2**: 提供 `.index(name)` 方法指定索引名称
3. **AC3.4.3**: 提供 `.column(col)` 方法添加索引列（支持多次调用创建复合索引）
4. **AC3.4.4**: 提供 `.unique()` 方法创建唯一索引
5. **AC3.4.5**: 提供 `.ifNotExists()` 方法添加 IF NOT EXISTS 子句
6. **AC3.4.6**: 支持表达式索引（如 `LOWER(email)`）
7. **AC3.4.7**: 支持部分索引（WHERE 条件）通过 `.where()` 方法
8. **AC3.4.8**: 提供 `.exec()` 方法执行 DDL 语句
9. **AC3.4.9**: 完整的使用示例验证

pub fn CreateIndexQuery(comptime T: type) type {
    return struct {
        const Self = @This();
        allocator: Allocator,
        db: *DB,
        table_name: []const u8,
        index_name: ?[]const u8,
        columns: ArrayList([]const u8),
        unique_flag: bool,
        if_not_exists_flag: bool,
        where_condition: ?[]const u8,

        pub fn index(self: *Self, name: []const u8) *Self;
        pub fn column(self: *Self, col: []const u8) *Self;
        pub fn unique(self: *Self) *Self;
        pub fn ifNotExists(self: *Self) *Self;
        pub fn where(self: *Self, condition: []const u8) *Self;
        pub fn build(self: *Self) ![]const u8;
        pub fn exec(self: *Self) !void;
        pub fn deinit(self: *Self) void;
    };
}

### PostgreSQL Index Types

**Simple Index**:
- 单列索引，用于加速单列查询
- 示例：`CREATE INDEX idx_email ON users (email)`

**Composite Index** (复合索引):
- 多列索引，用于加速多列组合查询
- 列顺序很重要（最左前缀原则）
- 示例：`CREATE INDEX idx_status_created ON users (status, created_at)`

**Unique Index** (唯一索引):
- 强制列值唯一性
- 类似 UNIQUE 约束，但更灵活（可以是表达式或部分索引）
- 示例：`CREATE UNIQUE INDEX idx_username ON users (username)`

**Expression Index** (表达式索引):
- 索引表达式而非原始列值
- 用于加速函数调用查询（如大小写不敏感搜索）
- 示例：`CREATE INDEX idx_email_lower ON users (LOWER(email))`

**Partial Index** (部分索引):
- 只索引满足 WHERE 条件的行
- 减小索引大小，提升性能
- 示例：`CREATE INDEX idx_active_users ON users (email) WHERE is_active = true`

### Key Implementation Notes

**SQL 构建示例**:
```zig
pub fn build(self: *Self) ![]const u8 {
    // 参数验证
    if (self.index_name == null) return error.IndexNameRequired;
    if (self.columns.items.len == 0) return error.ColumnsRequired;

    var sql_buf: std.ArrayList(u8) = .{};
    errdefer sql_buf.deinit(self.allocator);

    try sql_buf.appendSlice(self.allocator, "CREATE ");

    if (self.unique_flag) {
        try sql_buf.appendSlice(self.allocator, "UNIQUE ");
    }

    try sql_buf.appendSlice(self.allocator, "INDEX ");

    if (self.if_not_exists_flag) {
        try sql_buf.appendSlice(self.allocator, "IF NOT EXISTS ");
    }

    try sql_buf.appendSlice(self.allocator, self.index_name.?);
    try sql_buf.appendSlice(self.allocator, " ON ");
    try sql_buf.appendSlice(self.allocator, self.table_name);
    try sql_buf.appendSlice(self.allocator, " (");

    // 连接列（复合索引）
    const columns_joined = try std.mem.join(self.allocator, ", ", self.columns.items);
    defer self.allocator.free(columns_joined);
    try sql_buf.appendSlice(self.allocator, columns_joined);

    try sql_buf.appendSlice(self.allocator, ")");

    // 部分索引 WHERE 子句
    if (self.where_condition) |condition| {
        try sql_buf.appendSlice(self.allocator, " WHERE ");
        try sql_buf.appendSlice(self.allocator, condition);
    }

    defer sql_buf.deinit(self.allocator);
    return self.allocator.dupe(u8, sql_buf.items);
}
```
