### PostgreSQL DROP INDEX 特性

**IF EXISTS** [PostgreSQL Documentation]:
- 如果索引不存在，不报错，静默成功
- 用于幂等性脚本（可重复执行）

**CASCADE**:
- 级联删除依赖于该索引的对象
- PostgreSQL 中很少有对象依赖索引，此选项较少使用
- 与 DROP TABLE CASCADE 不同（DROP TABLE CASCADE 更常用）

**索引名全局性**:
- PostgreSQL 中索引名在数据库（schema）中全局唯一
- DROP INDEX 不需要指定表名
- 格式：`DROP INDEX index_name` （不是 `DROP INDEX table_name.index_name`）

**与 DROP TABLE 的区别**:
- DROP TABLE 可能有很多依赖（视图、外键等），CASCADE 常用
- DROP INDEX 依赖较少，CASCADE 较少使用

### Key Implementation Notes

**SQL 构建示例**:
```zig
pub fn build(self: *Self) ![]const u8 {
    // 参数验证
    if (self.index_name == null) return error.IndexNameRequired;

    var sql_buf: std.ArrayList(u8) = .{};
    errdefer sql_buf.deinit(self.allocator);

    try sql_buf.appendSlice(self.allocator, "DROP INDEX ");

    if (self.if_exists_flag) {
        try sql_buf.appendSlice(self.allocator, "IF EXISTS ");
    }

    try sql_buf.appendSlice(self.allocator, self.index_name.?);

    if (self.cascade_flag) {
        try sql_buf.appendSlice(self.allocator, " CASCADE");
    }

    defer sql_buf.deinit(self.allocator);
    return self.allocator.dupe(u8, sql_buf.items);
}
```

**链式调用示例**:
```zig
var drop_idx = try db.newDropIndex(User);
defer drop_idx.deinit();

try drop_idx
    .index("idx_users_email")
    .ifExists()
    .exec();

// 生成的 SQL:
// DROP INDEX IF EXISTS idx_users_email
```

**参数验证**:
```zig
pub fn exec(self: *Self) !void {
    if (self.index_name == null) {
        return error.IndexNameRequired;
    }

    const sql = try self.build();
    defer self.allocator.free(sql);

    try self.db.conn.execute(sql);
}
```
